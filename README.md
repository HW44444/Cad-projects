# CAD Projects

3D models I design in Autodesk Fusion. Each folder contains the editable CAD file (`.step`), a print-ready mesh (`.stl`), and a write-up of the design and what I learned.

## Projects

### [Phone Stand](phone-stand/)
A desk stand that holds my phone at a viewing angle *while it charges*, with a cutout at the base for the cable to pass through.
Size: 7.5 × 20 × 13.3 cm · Print-ready

### [Scent Holder](scent-holder/)
A desk organizer with dedicated pockets for my deodorant, lotion, and cologne — two round pockets for the cylindrical bottles and one rectangular pocket.
Needs resizing before printing (see its README)

## Skills used
- Sketching, extruding, and revolving in Autodesk Fusion
- Shelling to reduce material use and print time
- Fillets for strength and finish
- Designing around real measurements and tolerances
- Designing for manufacturing — matching parts to actual printer build volumes

## File formats
- **`.step`** — universal CAD format; opens and edits in any CAD program
- **`.stl`** — mesh format; drop straight into a slicer to 3D print
